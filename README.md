# Recipe API

A serverless Recipe API with semantic vector search, built with AWS SAM. Recipes are stored in DynamoDB and enriched with vector embeddings generated by Amazon Bedrock Titan Embed V2, enabling natural-language search using cosine similarity.

## Architecture

```
Client → API Gateway (REST) → Lambda Functions → DynamoDB (with vector index)
                                      ↓
                              Amazon Bedrock (Titan Embed V2)
```

- **Runtime:** Node.js 24, TypeScript, esbuild (ESM)
- **Infrastructure:** AWS SAM (CloudFormation)
- **Database:** DynamoDB with a vector index for semantic search
- **Embeddings:** Amazon Bedrock `amazon.titan-embed-text-v2:0` (1024 dimensions, cosine distance)
- **CI/CD:** GitHub Actions

## API Endpoints

| Method | Path | Description |
|--------|------|-------------|
| `POST` | `/recipes` | Create a recipe (generates embedding) |
| `GET` | `/recipes/{recipeId}` | Get a recipe by ID |
| `PUT` | `/recipes/{recipeId}` | Update a recipe (regenerates embedding) |
| `DELETE` | `/recipes/{recipeId}` | Delete a recipe |
| `POST` | `/recipes/search` | Semantic search across recipes |

## Recipe Schema

```json
{
  "name": "Spaghetti Carbonara",
  "cuisine": "italian",
  "dietary": [],
  "prepTimeMinutes": 10,
  "cookTimeMinutes": 20,
  "servings": 4,
  "description": "Classic Roman pasta with eggs, cheese, pancetta, and black pepper.",
  "ingredients": [
    { "name": "spaghetti", "amount": "400", "unit": "g" },
    { "name": "pancetta", "amount": "200", "unit": "g" }
  ],
  "steps": [
    "Boil pasta until al dente",
    "Cook pancetta until crispy",
    "Mix egg yolks with grated pecorino",
    "Toss hot pasta with pancetta off heat, then stir in egg mixture"
  ]
}
```

## Search

Send a natural-language query and get the top 5 most relevant recipes:

```bash
curl -X POST https://<api-url>/prod/recipes/search \
  -H "Content-Type: application/json" \
  -d '{"query": "something spicy with chicken"}'
```

The search function embeds the query using Bedrock, then performs a vector search against the `RecipeEmbeddingIndex` using DynamoDB's `SearchVectors` API with cosine similarity.

## How Embeddings Work

When a recipe is created or updated, the function builds a text representation from:
- Name and description
- Cuisine type
- Dietary tags
- Ingredient names
- Prep and cook times

This text is sent to Bedrock Titan Embed V2 to produce a 1024-dimension normalized vector, which is stored alongside the recipe in DynamoDB.

## Prerequisites

- Node.js 24+
- AWS SAM CLI
- AWS credentials with access to:
  - DynamoDB
  - Amazon Bedrock (Titan Embed V2 model)
  - CloudFormation
- Bedrock model access enabled for `amazon.titan-embed-text-v2:0` in your region

## Deployment

### Local deploy script

The deploy script runs `sam build && sam deploy` and then ensures the DynamoDB vector index exists on the deployed table:

```bash
AWS_PROFILE=<your-profile> npx tsx scripts/deploy.ts
```

### CI/CD (GitHub Actions)

Pushes to `main` (or PRs against it) that touch relevant files trigger the deploy workflow automatically. The workflow:

1. Installs dependencies
2. Assumes an IAM role via OIDC
3. Runs `sam build && sam deploy`
4. Creates the vector index if it doesn't exist

Required GitHub repository variables:
- `AWS_DEPLOY_ROLE_ARN` – IAM role ARN for deployment
- `AWS_REGION` – Target region (e.g. `us-east-1`)
- `ARTIFACTS_BUCKET` – S3 bucket for SAM deployment artifacts
- `CFN_EXECUTION_ROLE_ARN` – (optional) CloudFormation execution role

## Testing with Postman

A Postman collection (`Recipe-API.postman_collection.json`) is included with requests for all endpoints. The Create Recipe request auto-saves the returned `recipeId` for use in subsequent requests.

Import the collection and set the `baseUrl` variable to your deployed API URL.
